How the complexity index was built

Simple pixel statistics miss what people actually notice, so the pipeline extracts semantic, attentional and aesthetic cues before relating them to behavior.

  1. Curate thumbnails and define engagement

    A controlled dataset of 93 digital media thumbnails was assembled. Engagement was standardized as a Viral Ratio, then log-transformed so a few runaway hits would not dominate the fit.

  2. Extract visual features

    Semantic layout. YOLOv8 object detection across spatial grids measures how densely recognizable subjects fill the frame.
    Attention. Spectral residual saliency simulates where the eye lands, separating a clear focal point from unstructured load.
    Color. HSV color-space distributions capture palette variety and vibrancy.
    Texture. Sobel edge maps quantify high-frequency clutter.

  3. Combine into a Composite Complexity Index

    The standardized features were combined into one index describing how complex each thumbnail looks overall.

  4. Test the inverted U

    An OLS regression with a quadratic term mapped the index against log engagement. The Wundt Curve predicts a positive linear coefficient and a negative quadratic one.

What we found

The curve held: complexity raises engagement up to a point, then starts costing attention.

Limitations

With 93 thumbnails, the sample is small and the turning point carries real uncertainty. The results are associations, not proof that changing complexity causes engagement, and other factors such as topic, channel size and title also shape how a video performs.
